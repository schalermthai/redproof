## Limits

- One bounded fixture per host, not general production certification. Concurrency
  and durability were excluded; the hosts' approved Gate scopes differed.
- Only discover, design and build were invoked behaviorally. Challenge and
  review-pr were inventoried, not behaviorally evaluated.
- Implementation approval used chat. A real browser submission triggering a
  build was not tested. Browser checks were performed separately by a supervisor.
- This evidence does not cover Git-hosted installation/refresh, GitHub Actions,
  public marketplace approval, a full accessibility audit or adversarial security.
- These are historical results for the fingerprint above, not fresh evidence for
  a changed bundle. The readiness JSON references this report as an attestation;
  raw session transcripts and disposable fixture outputs are not committed.
